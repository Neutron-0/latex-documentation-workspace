\section{Structure of the Evaluation Module}
The evaluation harness comprises two Python source files:
\begin{itemize}
    \item \texttt{evaluator/metrics.py}: Defines mathematical functions for calculating Precision, Recall, and F1 score given raw counts of True Positives ($TP$), False Positives ($FP$), and False Negatives ($FN$):
    \begin{align}
    \label{eq:prec-rec-f1}
    \text{Precision} &= \frac{TP}{TP + FP} \\
    \text{Recall} &= \frac{TP}{TP + FN} \\
    \text{F1} &= \frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}
    \end{align}
    \item \texttt{evaluator/\_\_main\_\_.py}: The CLI entry point that emits the benchmark summary table during hackathon demonstration runs.
\end{itemize}

\section{Scientific Rationale for Disclosure}
Forensic code audit confirms that \texttt{evaluator/\_\_main\_\_.py} does not execute SQL queries against the Truth Vault to compute confusion matrices at runtime; rather, it formats and prints the predefined values in \Cref{tab:static-mock-metrics} for terminal presentation.

These values are preserved in this monograph strictly as historical documentation of the prototype's demonstration harness. They **must not** be cited as empirical performance claims.

\section{Blueprint for Dynamic Evaluation Harness}
To convert this demonstration harness into a dynamic benchmark, the evaluation script must be extended to execute the following algorithm:
\begin{enumerate}
    \item Connect directly to \texttt{postgres-wolverine} and extract all inferred identity pairs:
    \begin{equation}
    \mathcal{I} = \{ (a_i, a_j) \mid S(a_i, a_j) \ge 0.92 \}
    \end{equation}
    \item Connect to the air-gapped Truth Vault (\texttt{postgres-truth}) and extract the ground-truth identity mapping $\mathcal{G}$:
    \begin{equation}
    \mathcal{G} = \{ (a_i, a_j) \mid \text{Persona}(a_i) = \text{Persona}(a_j) \}
    \end{equation}
    \item Dynamically compute:
    \begin{align}
    TP &= |\mathcal{I} \cap \mathcal{G}| \\
    FP &= |\mathcal{I} \setminus \mathcal{G}| \\
    FN &= |\mathcal{G} \setminus \mathcal{I}|
    \end{align}
    \item Compute Precision, Recall, and F1 dynamically across all 89,605 accounts across parametric noise thresholds.
\end{enumerate}
