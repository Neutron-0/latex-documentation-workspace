\chapter{API Architecture}
\label{app:api}

The \texttt{wolverine-api} serves as the primary gateway to the Wolverine analytic pipeline, graph projection, and entity resolution systems. Implemented in Express (Node.js), it enforces strict role-based access control (RBAC) via the \texttt{X-Wolverine-Role} HTTP header.

\section{Security and Implementation Notes}
Authorization checks are handled by the \texttt{requireRole} middleware. If a request lacks a recognized role, it falls back to the \texttt{public\_demo} role, issuing a 401 Unauthorized for protected endpoints. Explicitly forbidden access returns a 403 Forbidden with standard Wolverine error envelopes. The graph projection endpoints enforce traversing the in-memory projected graphs strictly via bounded BFS; we purposefully avoid offloading arbitrary paths to PostgreSQL recursive CTEs.
